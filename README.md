## 核心功能

- **四大排盘体系**：紫微斗数、八字命理、六爻、奇门遁甲。
- **专业盘面与辅助工具**：多盘型、运限联动、关系图、反推定盘、紫占、批注与画板。
- **档案和案例管理**：本地 SQLite 存储、分类检索、导入导出、旧版数据迁移与云同步。
- **AI 研习**：盘面研习浮窗、AI 问答、盘面解析、紫微合盘、会话与报告管理。
- **知识内容**：知识库、提炼词条、书籍阅读器、个人笔记、资源市场与我的资产。
- **研习社区**：研习广场、互动回复、认证考试、消息中心与个人中心。
- **桌面体验**：多盘标签、独立浮窗、16 套主题、简繁切换及多格式导出。
